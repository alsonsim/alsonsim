# 💫 About Me:
I'm Alson — a Computer Engineering student who enjoys turning caffeine, curiosity, and questionable amounts of debugging into working software.

I build projects across AI, machine learning, robotics, embedded systems, and web development. From autonomous robots navigating mazes to AI-powered market dashboards, I like exploring how technology can solve real-world problems.

When I'm not coding, I'm probably learning something new, breaking something by accident, and then proudly fixing it. 🚀
